## 
## Project Outline

This project implements Adaptive Toeplitz Convolution, where convolution is reformulated as a matrix multiplication using Toeplitz matrices. An adaptive kernel is designed using the mean and standard deviation of the input discrete signal, and average pooling is applied to reduce dimensionality. The focus of the project is on mathematical formulation and linear algebra concepts, rather than application-level modeling.

## 
## Updates

Implemented Toeplitz matrix construction from a discrete signal

Designed an adaptive kernel based on signal statistics

Performed convolution using matrix multiplication

Compared Toeplitz convolution with standard (linear) convolution

Applied average pooling and visualized results
